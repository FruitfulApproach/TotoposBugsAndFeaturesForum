# ProofOrbitBugsAndFeatures

A bug 🐞 reporting and feature request forum for the ProofOrbit 🌌 desktop application as well as the ProofOrbit website.

## 🎯 Purpose

This repository serves as a centralized issue tracker for:
- **ProofOrbit Desktop Application** - Bug reports and feature requests for the desktop app
- **ProofOrbit Website** - Bug reports and feature requests for the website

## 🐛 Report a Bug

Found a bug? Help us fix it!

1. Click on the [**Issues**](../../issues) tab above
2. Click the **New Issue** button
3. Select **🐞 Bug Report**
4. Fill out the bug report form with as much detail as possible
5. Submit the issue

## ✨ Request a Feature

Have an idea for a new feature?

1. Click on the [**Issues**](../../issues) tab above
2. Click the **New Issue** button
3. Select **✨ Feature Request**
4. Describe your feature idea and use cases
5. Submit the issue

## 📋 Browse Existing Issues

Before submitting a new issue, please check if it already exists:
- [View all open issues](../../issues)
- [View bug reports](../../issues?q=is%3Aissue+is%3Aopen+label%3Abug)
- [View feature requests](../../issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement)

## 🏷️ Labels

Issues are organized using labels:
- **bug** - Something isn't working
- **enhancement** - New feature or request
- **desktop** - Related to ProofOrbit desktop application
- **website** - Related to ProofOrbit website
- **critical** / **high-priority** / **medium-priority** / **low-priority** - Priority levels
- **triage** - Needs initial review

See [`.github/LABELS.md`](.github/LABELS.md) for the complete label system.
